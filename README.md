# 📊 AI-Powered Data Analytics & Chatbot Engine

An interactive, end-to-end data processing and conversational analysis application built with **Streamlit**, **Pandas**, **Plotly**, and **OpenAI GPT-4o**.

## ✨ Features
- 📁 **Data Ingestion**: Support for CSV and Excel (`.xlsx`, `.xls`) datasets.
- 🧹 **Automated Cleaning**: Handles duplicate records and missing values automatically.
- 📈 **Interactive EDA**: Real-time descriptive statistics and dynamic Plotly charts (Bar, Line, Scatter, Histograms, Box Plots, Correlation Heatmaps).
- 💬 **AI Data Chatbot**: Query your datasets using natural language powered by OpenAI's `gpt-4o-mini` / `gpt-4o`.
- 🗄️ **Local Caching**: SQL-backed table caching for smooth session restoration.
